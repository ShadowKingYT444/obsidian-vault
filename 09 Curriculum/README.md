# Daily Polymath Curriculum

This folder turns the history/biography atlas into an ordered training program.

## How to use it

Open [[Today - Polymath]] each day. It points to the dated note for the current day.

The sequence uses four steps:

`predict -> read -> reconstruct -> transfer`

Do not read every linked note passively. The target is decision quality and causal models.

## Cadence

- **Monday–Saturday:** one focused case or comparison, usually 30–35 minutes.
- **Sunday:** retrieval and synthesis. No large new content load.
- **Day 0:** configure the Napoleon/Musk operating method before the historical sequence begins.

## If you miss a day

Do **not** binge three days to catch up. Continue with the oldest incomplete daily note. The date is a default pacing device, not a deadline.

## Completion

The first curriculum runs from **October 4, 2026 through December 27, 2026**. At the end, use the final week to build a second cycle from your weakest mechanisms.
