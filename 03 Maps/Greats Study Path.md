# Greats Study Path

Use this as a sequence, not a ranking of human worth.

[[Qin Shi Huang]] -> [[Qin Unification of China]]

Read:

[[George Washington]] · [[Abraham Lincoln]] · [[Winston Churchill]] · [[Nelson Mandela]]

[[John von Neumann]] · [[Alan Turing]] · [[Claude Shannon]] · [[Grace Hopper]]

## Final comparison

Read [[Napoleon and Elon Musk - Mechanism Comparison]] and try to falsify every row using another person in the vault.

If you can only explain a principle with one famous name, you probably have an anecdote, not a model.
