# Science, Technology, and Industry

## Discovery stack

Observation -> measurement -> model -> prediction -> experiment -> instrumentation -> community replication.

Key cases: [[Galileo Galilei]], [[Isaac Newton]], [[Michael Faraday]], [[James Clerk Maxwell]], [[Charles Darwin]], [[Marie Curie]], [[Albert Einstein]].

## Computation and information

[[John von Neumann]] -> programmable architectures and cross-domain mathematical synthesis.

[[Alan Turing]] -> computability and machine intelligence.

[[Claude Shannon]] -> information as a measurable abstraction.

[[Grace Hopper]] -> compilers and widening access to programming.

## Industrialization stack

Prototype -> reliable process -> standardized interfaces -> throughput -> distribution -> capital recycling -> scale.

Key cases: [[Industrial Revolution]], [[Thomas Edison]], [[Nikola Tesla]], [[John D Rockefeller]], [[Henry Ford]], [[Steve Jobs]], [[Elon Musk]].
