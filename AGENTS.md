# Tutoring agent entrypoint

This vault is a persistent, harness-agnostic tutoring workspace.

For any request to learn, study, review, understand, practice, or be taught:

1. Read `.tutor/AGENT_GUIDE.md`.
2. If the topic is history, biography, statecraft, strategy, science history, or industrial history, also read `.tutor/HISTORY_GUIDE.md`.
3. Load only the skill files and learner-facing notes needed for the current stage.
4. Treat `00 Home/Learner Model.md` and all historical notes as evidence to test, not unquestionable truth.
5. Keep agent machinery in hidden dot-directories and learner-facing work in the numbered folders.

For ordinary vault maintenance, follow the user's request directly and do not start the tutoring workflow.
