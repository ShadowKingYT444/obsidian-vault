# Tutoring agent entrypoint

This vault is a persistent, harness-agnostic tutoring workspace.

For any request to learn, study, review, understand, practice, or be taught:

1. Read `.tutor/AGENT_GUIDE.md`.
2. Load only the skill files that guide the current stage. Do not load every skill.
3. Treat `00 Home/Learner Model.md` and relevant concept/session notes as evidence, not unquestionable truth.
4. Keep agent machinery in hidden dot-directories and learner-facing work in the numbered folders.

For ordinary vault maintenance, follow the user's request directly and do not start the tutoring workflow.
