# Obsidian plugin setup

## Community plugins to install

### 1. Dataview — recommended

Use it for a live dashboard over concept-note metadata:

- concepts currently at the frontier
- fragile misconceptions
- concepts due for review
- recently mastered concepts
- current learning projects

The learning loop does not depend on Dataview, but the persistent learner model becomes much more useful with it.

### 2. Templater — recommended

Use it to create standardized session and concept notes with timestamps, frontmatter, and consistent sections.

### 3. Excalidraw — optional

Install only if you want editable hand-drawn/spatial diagrams in addition to Mermaid/SVG. It is not needed for the core system.

### 4. Obsidian Git — optional

Useful if you want automatic versioning/backup of the vault. Command-line Git also works well on Linux and may be simpler for an agent-managed vault.

## You do NOT need extra plugins for

- LaTeX-style equations / MathJax
- Mermaid diagrams
- Markdown
- callouts
- wikilinks / embeds
- backlinks
- Graph View

Obsidian supports those directly.

## Core plugins/features to enable

- Backlinks
- Graph view
- Properties view
- Templates (if you do not use Templater)
- Canvas (optional)
- Outline
