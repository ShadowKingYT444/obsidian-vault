# Speed as a Strategic Resource

> Tempo creates advantage when it lets an actor concentrate, decide, or learn before opponents can react.

## Mechanism

- Fast movement can create local numerical superiority.
- Fast decision loops exploit stale opponent information.
- Fast iteration compounds learning when errors are cheap and feedback is reliable.

## Cases

- Napoleon's corps often marched separately and concentrated rapidly at decisive points.
- Internet firms gained from rapid product iteration when deployment and feedback costs were low.
- Crisis response can benefit from speed if authority and information are aligned.

## Boundary conditions / failure cases

- Speed without verification magnifies error.
- Fast operations can outrun logistics and coordination.
- In irreversible domains, slower deliberation can dominate rapid action.

## Retrieval and transfer questions

- Which latency matters: sensing, decision, movement, or production?
- What error rate does greater speed create?
